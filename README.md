# Stormbreaker

기상예보로 풍력발전량을 예측하는 BARAM 2026 대회의 실험 기록입니다.
2025년의 시간별 발전량을 KPX 3개 그룹별로 예측합니다.

현재 `main`에는 데이터 설명, 검증 계획, 실험 기록이 있습니다.
학습 코드와 모델 파일은 이 브랜치에 포함되어 있지 않습니다.
실험 로그에 나오는 `experiments/`, `outputs/`, `submissions/`는 실험 당시의 로컬 경로입니다.

## 기록할 때 지키는 기준

2022~2023년으로 학습하고 2024년으로 검증합니다.
`kpx_group_3`은 2022년 정답이 없어 2023년만 학습에 사용합니다.
평가 기간에 제공되지 않는 실제 발전량과 SCADA는 추론 입력으로 쓰지 않습니다.

실험을 추가할 때는 기존 결과를 덮어쓰지 않고 실험 ID를 새로 붙입니다.
입력 데이터, 학습·검증 기간, 피처, 모델 설정을 적고
내부 검증과 리더보드 결과를 구분합니다. 제출하지 않은 실험은 미제출로 남깁니다.

## 변경 관리

공유 기준은 `main`이며, 개인 작업은 별도 브랜치에서 진행합니다.
PR에는 어느 실험을 기준으로 무엇을 바꿨는지, 같은 검증 구간에서 결과가 어땠는지 적습니다.
새 실험과 이전 기록의 오탈자 수정은 커밋을 나눕니다.

```text
실험: exp002에 터빈 거리 가중 피처 결과 기록
문서: KPX 그룹별 학습 기간과 발전량 단위 정리
```

원본 대회 데이터, 제출 CSV, 학습 모델은 `.gitignore`로 제외합니다.
이 저장소의 문서만으로 모델 학습을 재현할 수는 없습니다.
